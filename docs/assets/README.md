# README artwork

`archimind-hero.svg` is original vector artwork for this repository. Its isometric
room is a concept illustration, not a screenshot or generated design. The scan
line, tracing outline, and survey-point pulses use native SVG animation.
Reduced-motion preferences hide animated overlays while preserving the meaningful
static artwork. No scripts, external fonts, or remote image dependencies are used.

The five original technology badges combine original frames and labels with brand paths
from [Simple Icons](https://github.com/simple-icons/simple-icons), revision
`90646e4bf7f3b89df6c37e65baf3e7bc759a517c`:
