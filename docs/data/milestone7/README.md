# Edit a saved home in Town

Start with the [furnished woodland rehearsal](../../media/woodland-room-edits/README.md). Its commands create an editable copy and print a project URL. Keep that URL to reopen the home after saving a revision.

| Try it | What to look for |
|---|---|
| In **Plan** or **3D house**, click the salon coffee table. Check its ID and dimensions. Preview a move, rotation, replacement, duplicate or removal, then save. | A rejected change explains the obstruction. Check the 90 cm route when replacing the coffee table, reopen the revision in Walk and use Undo to recover the preceding state. [Furniture evidence](furniture/browser-receipt.json) |
| In **Renovate**, select a shared partition and drag it, or change its segment between wall, door and opening. Check and save. | Inspect the areas on both sides and walk across the opening. The first implementation supports eligible interior partitions in the generated gallery shell. [Partition after opening](renovation/renovation-opening.jpg) |
| Open **Finish chat**, select the salon and enter “Dark green walls”. Save. Select the whole home and enter “Walnut floors throughout”. | Change scope to a supported object for a single furniture finish. Inspect the saved surfaces in Plan, 3D and Walk. Colors represent design proposals. Supplier finish samples still require confirmation. |
| Enter a room in **Walk**, frame a detail, open **Compare revisions** and select **Bookmark current walking view**. Save an edit, then reopen Compare and choose that room's saved camera. | Drag the divider over the two adjacent revisions. Select the Blender comparison for a rendered view of the same revision and camera. The standard furnished home needs a completed local Blender proof. Saving a new camera in the same room replaces its previous framing. [Salon comparison](cameras/compare-salon.jpg) · [Phone comparison](cameras/narrow.jpg) |
| Open **Build a home from room photos** and add photos and measurements for two adjoining rooms. Correct the inferred geometry and confirm matching openings on both sides before saving. | The local importer supports two to four rectangular rooms in a west-to-east row with a common depth. Reopen the saved project, review the source photos, and walk between rooms. The browser example uses synthetic photos and explicit dimensions. [Photo-home walkthrough](photo-home/README.md) |

The saved geometry and dimensions describe the model. A client or designer can use them to plan what to verify on site.
