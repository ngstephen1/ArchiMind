# Bookmarked room comparisons

Desktop Chrome at 1440 × 900 saved walking cameras for the salon, study and living room. On reopening project `29f9747c-e87b-41dd-b3cd-4199d31b0e52` at revision 4, all three cameras produced an adjacent-revision wipe. At 390 × 844, **Walk from this saved view** restored the study position; bookmarking the restored position again resolved to the same room.

| Salon | Study | Living room |
|---|---|---|
| [Desktop wipe](compare-salon.jpg) | [Desktop wipe](compare-study.jpg) · [Phone wipe](narrow.jpg) | [Desktop wipe](compare-living.jpg) |

Each camera stores its room, eye, target, vertical field of view and aspect ratio. The comparison restores the original frame even when the browser window now has different proportions. A bookmarked view outside either revision's room cannot be compared. The [photo-home proof](../photo-home/integration.json) records a separate browser comparison with a real local Cycles render.
