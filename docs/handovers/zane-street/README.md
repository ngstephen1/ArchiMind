They do not locate or measure a present-day client's room.

The nominal dimensions convert to 3.3528 × 4.2672 m. The drawing shows an irregular perimeter. Multiplying the dimensions yields a rectangular reference area only. Preserve the bay as unresolved geometry until independently measured. Ceiling height, present condition, usable door clearance, sill elevations, power, HVAC and furniture to retain are unknown. No budget, currency or current site access was supplied.

## Rebuild the packet

From the repository root, run the following with Python 3, curl, Poppler and Chrome/Chromium installed. The command downloads four source files from the Library of Congress, verifies their pinned SHA-256 values, and packages them with the PDF and a machine-readable evidence record. Set CHROME_BIN to override browser discovery. Downloads are under 1 MiB in total.

```sh
python3 scripts/build_archival_bedroom.py --output output/measured-case/edition
```

## Use on a project

1. Confirm the site address, owner authorization and current site access before proposing an intervention. Historical documentation alone cannot establish whether the building survives.
2. At the visit, start at a permanent corner. Record each finished-face run in order, bay angles, two check diagonals, floor-to-ceiling heights and changes of level. Key each measurement and original photo to a dated plan. Include a scale where appropriate.
3. Measure jambs, clear opening widths, operating swings, sill and head elevations, window operation, trim projection, outlets, radiator and other fixed elements. Resolve differences between the field measurements and the archive.
4. Have the client identify the items to keep, provide a currency and budget, and approve the option to develop. Record supplier quotations, dates, lead times and installation exclusions against the chosen revision.

The source record and packet are an archival intake exercise. The furnished Studio House options and Blender renders depict a separate design. Use the two packages independently.
